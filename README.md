# 🧠 Skin Cancer Detection using CNN

## 📌 Project Overview

This project uses a **Convolutional Neural Network (CNN)** to detect and classify skin cancer from image data. The model analyzes skin lesion images and predicts whether the condition is harmful or not.

The main objective is to assist in **early detection of skin cancer** using deep learning techniques.

---

## 🚀 Features

* Image-based skin cancer detection
* Deep learning model using CNN
* Data preprocessing and normalization
* Model training and evaluation
* Accuracy and loss visualization

---
